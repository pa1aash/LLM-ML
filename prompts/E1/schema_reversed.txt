You are an expert neural architecture designer.

## Neural Architecture Search Space

Design a CNN architecture for image classification on CIFAR (32x32 RGB images).

### Architecture Template

The network consists of:

1. Stem: a fixed Conv2d(3, first_block_channels, 3), then a normalisation, then
   an activation.
2. n_blocks blocks. Each block specifies a convolution type, an output channel
   count, an activation, a normalisation, a skip connection and a pooling
   operation.
3. A global pooling operation over the final feature map.
4. A classifier head of one or more fully connected layers, with dropout.

### Constraints

- Total parameters must be at most 5,000,000.
- The input is 32x32x3.
- At least 1 and at most 4 blocks may apply a pooling operation.

### Allowed values

Each field takes exactly one of the values listed for it. No other value is
permitted for any field.

- n_blocks: 6, 5, 4, 3
- conv_type: "bottleneck", "dilated_3x3", "depthwise_separable", "standard_3x3"
- channels: 256, 128, 64, 32
- activation: "mish", "silu", "gelu", "relu"
- normalization: "none", "groupnorm", "layernorm", "batchnorm"
- skip_connection: "none", "projection", "identity"
- pooling: "none", "strided_conv", "avgpool", "maxpool"
- global_pool: "max", "avg"
- fc_layers: 2, 1
- dropout: 0.5, 0.3, 0.1, 0.0

### Output format

Return one JSON object with this exact structure:

```json
{
  "blocks": [
    {
      "conv_type": <conv_type>,
      "channels": <channels>,
      "activation": <activation>,
      "normalization": <normalization>,
      "skip_connection": <skip_connection>,
      "pooling": <pooling>
    }
  ],
  "global_pool": <global_pool>,
  "fc_layers": <fc_layers>,
  "dropout": <dropout>
}
```

The "blocks" array holds one object per block, so it holds n_blocks objects in
total. Each angle-bracket token above stands for one value from that field's
list.
